# Разработка проекта

## Подготовка окружения

1. Создайте и активируйте виртуальное окружение Python 3.11.
2. Установите зависимости командой `pip install -r requirements.txt`.
3. Запустите `python check_project.py --quick`.

## Правила изменений

- создавайте отдельную ветку от актуального `main`;
- делайте один содержательный шаг в одном коммите;
- не редактируйте уже применённые миграции, добавляйте новую версию;
- для нового поведения добавляйте автоматический тест;
- сохраняйте учебные тексты в UTF-8;
- не добавляйте SQLite-базы, `.env`, виртуальные окружения и отчёты покрытия.

## Проверка перед pull request

```bash
python check_project.py
git diff --check
```

Pull request должен кратко объяснять изменение, его назначение и способ
проверки. Все проверки GitHub Actions должны завершиться успешно.
