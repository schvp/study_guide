## Цель раздела

Булева алгебра — математический язык для описания логических состояний и цифровых схем. В этой главе вводятся переменные со значениями 0 и 1, операции НЕ, И и ИЛИ, таблицы истинности и несколько основных законов преобразования выражений.

После изучения вы сможете вычислять простые логические выражения, строить для них таблицы истинности и применять базовые законы для упрощения схем.

## Логические переменные и выражения

Логическая переменная принимает одно из двух значений: 0 или 1. В цифровой схеме этим значениям соответствуют логические состояния, распознаваемые по электрическим сигналам. Сами числа 0 и 1 в булевой алгебре обозначают состояния, а не конкретные напряжения.

Логическое выражение связывает переменные операциями. Например, выражение A И B равно 1 только тогда, когда обе переменные равны 1. Результат каждой операции определяется её правилом, независимо от того, что физически представляют A и B.

## Операция НЕ

Операция НЕ инвертирует значение переменной: если A = 0, то НЕ A = 1; если A = 1, то НЕ A = 0. Инверсию также называют логическим отрицанием и обозначают чертой над переменной или символом ¬A.

Таблица истинности перечисляет все допустимые наборы входов и результат операции. Для НЕ вход один, поэтому достаточно рассмотреть оба его значения: при A = 0 результат ¬A равен 1; при A = 1 результат ¬A равен 0.

## Операция И

Операция И, или конъюнкция, даёт 1 только при A = 1 и B = 1. Во всех остальных случаях результат равен 0. Её записывают как A И B, A ∧ B или A · B.

Таблица истинности для двух переменных содержит четыре набора: 00, 01, 10 и 11. Для операции И результаты в этом порядке равны 0, 0, 0 и 1. Число наборов равно 2ⁿ, где n — количество независимых двоичных входов.

## Операция ИЛИ

Операция ИЛИ, или дизъюнкция, даёт 1, если хотя бы одна из переменных равна 1. Результат равен 0 только для набора A = 0, B = 0. Запись: A ИЛИ B, A ∨ B или A + B.

Для наборов 00, 01, 10 и 11 результаты ИЛИ равны 0, 1, 1 и 1. В булевой алгебре знак «+» здесь означает логическое ИЛИ, а не обычное сложение целых чисел.

## Приоритет операций и скобки

В выражении ¬A ∧ B сначала вычисляется НЕ A, затем результат объединяется с B операцией И. Скобки позволяют явно задать порядок: ¬(A ∧ B) означает инверсию результата И, а (¬A) ∧ B — И между инвертированной A и B. Эти выражения в общем случае различаются.

Чтобы вычислить выражение, перечислите все наборы его входных переменных и последовательно примените операции в заданном порядке. Например, для A = 0 и B = 1: ¬A ∧ B = 1 ∧ 1 = 1, а ¬(A ∧ B) = ¬(0 ∧ 1) = ¬0 = 1. На другом наборе результаты могут разойтись: при A = 1 и B = 1 первое выражение равно 0, второе также равно 0; при A = 0, B = 0 первое равно 0, второе равно 1.

## Основные законы булевой алгебры

Законы булевой алгебры позволяют преобразовать выражение, не меняя его результат для любых входных значений. Их используют, чтобы уменьшать число логических элементов или делать схему проще для анализа.

Законы тождества: A ∧ 1 = A и A ∨ 0 = A. Нейтральное значение не меняет результат соответствующей операции.

Законы доминирования: A ∧ 0 = 0 и A ∨ 1 = 1. В этих случаях результат полностью определяется постоянным значением.

Законы идемпотентности: A ∧ A = A и A ∨ A = A. Повторение одной и той же переменной не добавляет новой информации.

Законы дополнения: A ∧ ¬A = 0 и A ∨ ¬A = 1. Переменная и её инверсия не могут одновременно быть истинными и всегда покрывают оба возможных состояния.

Законы двойного отрицания: ¬(¬A) = A. Две последовательные инверсии возвращают исходное значение.

Переместительный закон допускает перестановку операндов: A ∧ B = B ∧ A и A ∨ B = B ∨ A. Сочетательный закон разрешает менять группировку: (A ∧ B) ∧ C = A ∧ (B ∧ C), и аналогично для ИЛИ.

## Пример упрощения

Рассмотрим выражение A ∧ 1 ∨ A ∧ 0. Сначала применим законы тождества и доминирования: A ∧ 1 = A, а A ∧ 0 = 0. Получаем A ∨ 0. По закону тождества итог равен A.

Проверка по значениям подтверждает результат: при A = 0 исходное выражение равно 0, при A = 1 оно равно 1. Значит, выражение эквивалентно одной переменной A и для реализации не нужны дополнительные логические операции.
