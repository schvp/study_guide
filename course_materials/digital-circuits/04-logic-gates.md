## Цель раздела

Логические элементы — базовые узлы цифровой схемы, которые реализуют операции булевой алгебры. В этой главе рассмотрим элементы НЕ, И, ИЛИ, NAND, NOR и исключающее ИЛИ, их поведение и способы проверки по таблицам истинности.

После изучения вы сможете определить функцию логического элемента по его входам и выходу, составить таблицу истинности простого элемента и объяснить, почему NAND и NOR называют универсальными.

## От логического выражения к элементу

Булева алгебра описывает, какой результат должна выдавать схема для каждого набора входов. Логический элемент — электронный узел, который реализует одну такую операцию. У него есть входы и выход, а реальные напряжения на выводах должны соответствовать электрическим требованиям выбранной микросхемы.

В условных схемах функции элементов обозначают графическими символами. В разных стандартах оформления детали символов могут отличаться, поэтому при чтении конкретной схемы следует учитывать применяемый стандарт. Основное поведение элемента надёжнее всего проверять по таблице истинности и документации компонента.

## Инвертор — НЕ

Инвертор имеет один вход и выдаёт противоположное логическое значение: при входе 0 выход равен 1, при входе 1 выход равен 0. Его функцию записывают как Y = ¬A.

Инвертор не меняет физический сигнал мгновенно: реальная микросхема имеет задержку распространения и электрические ограничения. В логических задачах, если задержки отдельно не рассматриваются, считают, что выход соответствует устойчивому значению входа.

## Элементы И и ИЛИ

Элемент И с двумя входами выдаёт 1 только при A = 1 и B = 1. Функция записывается Y = A ∧ B. Он подходит для условий, когда для активации выхода должны одновременно выполняться оба требования.

Элемент ИЛИ выдаёт 1, когда единица присутствует хотя бы на одном входе. Функция записывается Y = A ∨ B. Он подходит для объединения альтернативных условий.

Для обоих элементов рассматривают четыре входных набора. В порядке 00, 01, 10, 11 выход И равен 0, 0, 0, 1, а выход ИЛИ равен 0, 1, 1, 1. Таблица истинности тем самым полностью определяет их логическое поведение.

## Элементы NAND и NOR

NAND, или И-НЕ, выполняет И, а затем инвертирует результат: Y = ¬(A ∧ B). Его выход равен 0 только при входах 11; для наборов 00, 01, 10, 11 выходы равны 1, 1, 1, 0.

NOR, или ИЛИ-НЕ, инвертирует результат ИЛИ: Y = ¬(A ∨ B). Его выход равен 1 только при входах 00; для наборов 00, 01, 10, 11 выходы равны 1, 0, 0, 0.

NAND и NOR называют универсальными элементами: комбинациями только NAND можно построить инвертор, И и ИЛИ; то же верно для одного лишь NOR. Например, инвертор из NAND получается соединением обоих входов с A: ¬A = ¬(A ∧ A). Свойство универсальности важно при проектировании, поскольку всю комбинационную логику можно реализовать выбранным семейством элементов.

## Исключающее ИЛИ — XOR

Элемент XOR выдаёт 1, когда входы различаются, и 0, когда они одинаковы. Для двух входов его функция записывается Y = A ⊕ B. В порядке наборов 00, 01, 10, 11 результаты равны 0, 1, 1, 0.

XOR встречается в сумматорах: он формирует бит суммы двух входных битов без учёта переноса. В отличие от обычного ИЛИ, при двух единичных входах XOR выдаёт 0.

## Как построить и проверить таблицу истинности

Для n двоичных входов существует 2ⁿ различных входных наборов. Выпишите наборы в одном и том же порядке, затем вычислите выражение для каждой строки. Для составной схемы добавляйте промежуточные столбцы: это помогает проверить каждый логический узел отдельно и обнаружить ошибку.

Для примера Y = ¬A ∨ B при наборах 00, 01, 10, 11 сначала получаем ¬A: 1, 1, 0, 0. Затем применяем ИЛИ с B и получаем Y: 1, 1, 1, 1. Последовательное вычисление промежуточного результата делает таблицу проверяемой.

## Проверьте себя

1. Какой выход элемента И для набора входов A = 1, B = 0?

2. Чем отличается поведение XOR от ИЛИ при входном наборе 11?

3. Для какого входного набора NOR выдаёт 1?

4. Как из NAND получить инвертор?

5. Сколько строк содержит полная таблица истинности для четырёх независимых входов?

Ответы: выход И равен 0; для 11 элемент ИЛИ выдаёт 1, а XOR — 0; NOR выдаёт 1 при входах 00; соединить оба входа NAND с одной переменной, получив ¬(A ∧ A) = ¬A; таблица содержит 2⁴ = 16 строк.
