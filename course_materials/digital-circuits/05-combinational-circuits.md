## Цель раздела

Комбинационная схема преобразует входные логические сигналы в выходные по заданной функции. В отличие от последовательностной схемы, она не хранит предыдущее состояние: при фиксированных входах её логический выход определяется текущими входами.

После изучения вы сможете отличать комбинационную схему от последовательностной, составлять таблицу истинности по условию задачи и переходить от неё к булевым выражениям для выходов.

## Комбинационные и последовательностные схемы

В комбинационной схеме нет логической памяти, поэтому для её описания достаточно перечислить текущие входы и соответствующие им выходы. Примеры таких устройств — сумматоры, дешифраторы, кодеры, мультиплексоры и компараторы.

Последовательностная схема хранит состояние, поэтому её поведение зависит от текущих входов и значения, сохранённого ранее. Регистры и счётчики относятся к последовательностным устройствам. Для них важны память и, часто, тактовые сигналы. Подробно такие схемы рассматриваются в следующих главах.

Реальная комбинационная схема может иметь задержку распространения сигнала: после изменения входов требуется время, прежде чем выход установится. Если временные характеристики не входят в условие, логический анализ рассматривает установившиеся значения.

## От условия задачи к таблице истинности

Проектирование начинают с точного описания задачи: что означают входные и выходные переменные и при каких условиях выход должен принимать 0 или 1. Это помогает избежать неоднозначности ещё до выбора элементов.

Для n независимых двоичных входов таблица содержит 2ⁿ строк. В каждой строке записывают один входной набор и требуемые значения всех выходов. Если выходов несколько, для каждого строят отдельную булеву функцию, используя ту же таблицу.

Например, если выход активен только при определённом сочетании входов, это условие отмечают единицей в соответствующей строке, а в остальных строках ставят нули. Таблица становится однозначной спецификацией логического поведения устройства.

## Получение булевых выражений

После заполнения таблицы можно получить выражение для каждого выхода. Один из прямых способов — записать минтерм для каждой строки, где выход равен 1, а затем объединить эти минтермы операцией ИЛИ. В минтерме переменная записывается без инверсии, если в строке она равна 1, и с инверсией, если равна 0.

Для двух входов A и B строка A = 0, B = 1 соответствует минтерму ¬A ∧ B. Строка A = 1, B = 1 соответствует A ∧ B. Если выход равен 1 на этих двух строках, исходное выражение можно записать как (¬A ∧ B) ∨ (A ∧ B). Затем применяют законы булевой алгебры, чтобы упростить выражение.

Полученная функция может быть реализована отдельными логическими элементами. При выборе структуры учитывают требуемую функцию, доступные элементы, количество входов и ограничения конкретных микросхем. После упрощения полезно проверить эквивалентность исходной таблице по всем входным наборам.

## Последовательность проектирования

1. Определите входы, выходы и смысл логических значений.

2. Запишите требование к выходу для каждого возможного набора входов.

3. Составьте таблицу истинности и проверьте, что рассмотрены все 2ⁿ наборов.

4. Выведите булевы выражения для выходов.

5. Упростите выражения, используя законы булевой алгебры.

6. Реализуйте функции логическими элементами и повторно проверьте таблицу.

Эта последовательность отделяет смысл задачи от способа её реализации. Если после упрощения схема изменилась, проверка по исходной таблице помогает убедиться, что требуемое поведение сохранено.

## Пример: полусумматор

Полусумматор складывает два однобитных числа A и B. У него два выхода: S — младший бит суммы, C — перенос в следующий разряд. Возможные результаты: 0 + 0 = 00₂, 0 + 1 = 01₂, 1 + 0 = 01₂ и 1 + 1 = 10₂.

Таблица поведения:

A = 0, B = 0: S = 0, C = 0

A = 0, B = 1: S = 1, C = 0

A = 1, B = 0: S = 1, C = 0

A = 1, B = 1: S = 0, C = 1

Выход суммы равен 1, когда входы различаются, поэтому S = A ⊕ B. Перенос возникает только тогда, когда оба входа равны 1, поэтому C = A ∧ B. Так таблица истинности непосредственно задаёт две функции и схему из элементов XOR и И.

Полусумматор не принимает перенос из предыдущего разряда. Для сложения старших разрядов, куда уже может поступать входной перенос, используют полный сумматор; он рассматривается как развитие этой схемы.

## Пример: мультиплексор 2 к 1

Мультиплексор выбирает один из информационных входов и передаёт его на выход. В мультиплексоре 2 к 1 есть данные D₀ и D₁, управляющий вход S и выход Y. При S = 0 выбирается D₀, а при S = 1 — D₁.

Таблица задаётся двумя условиями: S = 0 приводит к Y = D₀ независимо от D₁; S = 1 приводит к Y = D₁ независимо от D₀. Булево выражение, объединяющее эти случаи, имеет вид Y = (¬S ∧ D₀) ∨ (S ∧ D₁).

Каждое слагаемое пропускает выбранные данные только при соответствующем значении S. При S = 0 выражение сводится к D₀, а при S = 1 — к D₁. Поэтому мультиплексор можно рассматривать как управляемый переключатель логических сигналов.

## Пример: дешифратор 2 в 4

Дешифратор преобразует двоичный код на входе в один активный выход. У дешифратора 2 в 4 есть два входа A и B и четыре выхода Y₀, Y₁, Y₂, Y₃. В активном высоком варианте для каждого входного кода ровно один выход равен 1.

Для входов A B = 00 активен Y₀; для 01 — Y₁; для 10 — Y₂; для 11 — Y₃. Соответствующие функции: Y₀ = ¬A ∧ ¬B, Y₁ = ¬A ∧ B, Y₂ = A ∧ ¬B, Y₃ = A ∧ B.

Каждая функция является минтермом одной строки таблицы истинности. Такой дешифратор полезен, когда код нужно преобразовать в набор взаимоисключающих управляющих сигналов, например для выбора одной из четырёх линий.

## Проверьте себя

1. Чем комбинационная схема отличается от последовательностной с точки зрения зависимости выхода?

2. Сколько строк должна содержать полная таблица истинности для пяти независимых двоичных входов?

3. Для каких значений A и B перенос C полусумматора равен 1? Как при этом ведёт себя выход суммы S?

4. Какой вход мультиплексора 2 к 1 передаётся на выход при S = 1?

5. Какой выход дешифратора 2 в 4 активен при входном коде A B = 10?

Ответы: комбинационная схема зависит от текущих входов и не хранит предыдущее логическое состояние; таблица содержит 2⁵ = 32 строки; перенос равен 1 при A = 1 и B = 1, при этом S = 0; при S = 1 выход равен D₁; для кода 10 активен Y₂.
