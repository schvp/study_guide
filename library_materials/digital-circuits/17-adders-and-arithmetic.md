## Полусумматор

Полусумматор складывает два одноразрядных числа A и B. Бит суммы равен A XOR B, перенос — A AND B. Название «полу» указывает, что узел не принимает перенос из предыдущего разряда.

Полусумматор подходит для младшего разряда простейшей цепочки, но остальные разряды требуют третьего входа.

## Полный сумматор

Полный сумматор принимает A, B и входной перенос Cin. Сумма равна A XOR B XOR Cin. Выходной перенос активен, когда минимум два из трёх входов равны единице:

Cout = AB + A·Cin + B·Cin.

Его можно собрать из двух полусумматоров и элемента ИЛИ. Первый складывает A и B, второй добавляет Cin, а их переносы объединяются.

## Цепной перенос

Многоразрядный ripple-carry сумматор соединяет Cout каждого разряда с Cin следующего. Структура проста, но результат старшего разряда ждёт распространения переноса через всю цепочку. Максимальная задержка растёт с разрядностью.

После изменения входов промежуточные биты суммы могут несколько раз переключиться. Использовать результат следует только после времени установления либо зарегистрировать его на следующем такте.

## Формирование и распространение переноса

Для разряда вводят generate G = AB и propagate P = A XOR B. Тогда Cout = G + P·Cin. Раскрывая выражения для нескольких разрядов, можно вычислять переносы параллельно. Схема carry look-ahead требует больше логики, но сокращает критический путь.

Современные FPGA имеют специализированные быстрые цепи переноса. Ручная замена сложения сетью обычных элементов часто ухудшает результат синтеза.

## Сложение и вычитание

В дополнительном коде A − B = A + NOT B + 1. Перед каждым битом B ставят XOR с управляющим сигналом SUB, а SUB подают как начальный перенос. При SUB = 0 узел складывает A и B, при SUB = 1 инвертирует B и прибавляет единицу.

## Флаги

Carry показывает перенос за разрядную сетку и полезен для беззнаковой арифметики. Overflow показывает знаковое переполнение и равен XOR переносов во вход и из старшего разряда. Zero получают операцией ИЛИ-НЕ над всеми битами результата. Negative обычно копирует старший бит.

Флаги нужно трактовать вместе с выбранным типом числа. Carry не заменяет overflow.

## Проверка

Обязательно проверяют ноль, максимальные значения, длинную цепочку переноса, сложение чисел разных знаков и оба вида переполнения. Для каждого набора должен выполняться инвариант: A + B + Cin = Sum + 2^n·Cout для беззнаковых n-разрядных входов.
