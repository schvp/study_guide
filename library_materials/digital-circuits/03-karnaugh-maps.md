## Назначение карты

Карта Карно визуально объединяет соседние наборы переменных, для которых функция имеет одинаковое значение. Соседние клетки отличаются ровно одним битом, поэтому при объединении соответствующая переменная исключается. Метод удобен для функций до четырёх переменных и применим к пяти-шести переменным при аккуратной работе с несколькими картами.

## Порядок клеток

Строки и столбцы располагают в коде Грея: 00, 01, 11, 10. Между соседними подписями изменяется один бит. Крайние строки также соседние, как и крайние столбцы: карта мысленно свёрнута по горизонтали и вертикали.

Обычный двоичный порядок 00, 01, 10, 11 нарушает соседство между 01 и 10. Использование такого порядка приводит к неверным группам и формулам.

## Минимизация ДНФ

Для получения дизъюнктивной нормальной формы отмечают клетки, где функция равна единице. Затем строят прямоугольные группы размером 1, 2, 4, 8 или 16 клеток.

Правила группировки:

- каждая единица должна входить хотя бы в одну группу;
- группа содержит только единицы и допустимые безразличные состояния;
- размер группы — степень двойки;
- прямоугольник может пересекать границу карты;
- группы могут перекрываться;
- нужно стремиться к максимально большим группам;
- одиночную клетку оставляют только тогда, когда расширить её невозможно.

Для каждой группы оставляют переменные, значение которых внутри неё не меняется. Если A везде равно единице, в конъюнкцию входит A. Если B везде равно нулю, входит отрицание B. Переменная, принимающая оба значения, исчезает.

## Пример рассуждения

Пусть группа из четырёх клеток покрывает обе строки для переменной A и два столбца, где B = 1. Значение A внутри группы меняется, поэтому A исключается. Если C тоже меняется, а B остаётся единицей, вся группа даёт импликанту B.

Группа из двух клеток, где A = 0, C = 1, а B меняется, даёт произведение отрицание A и C. Итоговая функция — дизъюнкция импликант всех выбранных групп.

## Минимизация КНФ

Для конъюнктивной нормальной формы группируют нули. Постоянная единица переменной внутри нулевой группы входит в дизъюнкцию с отрицанием, а постоянный ноль — без отрицания. Полученные суммы соединяют операцией И.

Важно не смешивать правила ДНФ и КНФ. При группировке единиц строятся произведения, при группировке нулей — суммы.

## Безразличные состояния

Состояние X можно считать нулём или единицей так, чтобы получить более крупную группу. Использовать каждый X необязательно. Например, в преобразователе BCD комбинации 1010…1111 не возникают при корректном входе и могут помочь упростить дешифратор.

Безразличное состояние допустимо только при гарантии, что соответствующий вход невозможен либо результат для него действительно неважен. Если некорректная комбинация может появиться во время переходного процесса, произвольный выход способен создать опасный импульс.

## Существенные импликанты

Группа является существенной, если содержит единицу, не покрываемую никакой другой максимальной группой. Такие группы включают в результат обязательно. После них выбирают минимальный набор групп для оставшихся единиц.

Практический порядок:

1. найдите все максимально большие группы;
2. отметьте единицы с единственным вариантом покрытия;
3. включите существенные группы;
4. покройте оставшиеся клетки наименьшим числом импликант;
5. выпишите формулу и проверьте её таблицей истинности.

## Проверка и ограничения

Минимальная формула по числу литералов не всегда даёт лучшую физическую схему. Нужно учитывать доступные элементы, задержку, нагрузку и опасности переключения. Для устранения статической опасности иногда намеренно добавляют избыточную консенсусную импликанту.

Карта Карно минимизирует логическое выражение, но инженер после неё должен проверить временное поведение реализации.
