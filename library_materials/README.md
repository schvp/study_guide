# Материалы библиотеки

Каждый материал хранится парой файлов: JSON с метаданными и Markdown с учебным текстом.
Файлы группируются по каталогу курса. При запуске приложения материалы добавляются или
обновляются в SQLite по сочетанию `course` и `slug`.

Обязательные поля JSON проверяются загрузчиком `library_content.py`. Позиции и адреса
материалов должны быть уникальны внутри курса.
